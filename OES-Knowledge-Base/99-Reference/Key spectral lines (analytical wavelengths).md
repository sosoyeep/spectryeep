# Key spectral lines (analytical wavelengths)

Representative analytical lines used in spark OES. **Indicative values for orientation** — exact
lines chosen depend on matrix, concentration and instrument; consult the instrument's line
library and the relevant [[Standards overview|method standard]]. Lines below **~200 nm** are
**vacuum-ultraviolet** and require [[Vacuum vs purged vs sealed optics|vacuum/purged optics]].

## Light elements (VUV — the OES advantage)

| Element | Line (nm, approx.) | Note |
|---|---|---|
| Carbon (C) | **193.0** | The reason for vacuum/UV optics; XRF can't do this |
| Phosphorus (P) | ~178.3 | VUV |
| Sulfur (S) | ~180.7 | VUV |
| Nitrogen (N) | ~149 / 174 | Deep VUV; demanding |
| Boron (B) | ~182 / 249.7 | |

## How lines are chosen
A good analytical line is **sensitive**, **interference-free** at your composition, and matched
to the concentration range (major elements often use *weaker* lines to avoid
[[Spectral interferences and matrix effects|self-absorption]]; traces use *strong* lines). See
[[Atomic emission and spectral lines]].
