# Glossary

Plain-language definitions of OES and metals-analysis terms. Links point to the full note.

- **AES (Atomic Emission Spectrometry)** — see [[Optical Emission Spectrometry (OES)]].
- **Analytical line** — the spectral line chosen to quantify an element →
  [[Key spectral lines (analytical wavelengths)]].
- **Argon** — inert working gas of the spark discharge → [[Argon supply and purity]].
- **Burn / burn spot** — the area sparked during one analysis.
- **Carbon equivalent (CE/CEV)** — formula combining C, Si, P (cast iron/steel) →
  [[Cast iron and carbon equivalent]].
- **CCD / CMOS** — solid-state array detectors → [[Detectors - PMT vs CCD-CMOS]].
- **CRM (Certified Reference Material)** — composition-certified sample for calibration →
  [[Calibration and certified reference materials]].
- **Counter-electrode** — tungsten electrode the spark jumps to →
  [[Spark stand and counter electrode]].
- **Detection limit (LOD)** — smallest reliably detectable amount →
  [[Detection limits, precision and accuracy]].
- **Diffraction grating** — disperses light into wavelengths →
  [[Diffraction gratings and focal length]].
- **Drift** — slow change in response over time → [[Type standardization and drift correction]].
- **Excitation source** — generates the discharge → [[Excitation source (spark generator)]].
- **Focal length** — optic size; sets resolution (401 mm, 750 mm) →
  [[Diffraction gratings and focal length]].
- **GD-OES** — *glow-discharge* OES, a different (surface/depth) technique → see
  [[ISO and EN methods]] (ISO 14707).
- **IEC (inter-element correction)** — math correction for interferences →
  [[Spectral interferences and matrix effects]].
- **Internal standard** — matrix line used to ratio intensities →
  [[Calibration and certified reference materials]].
- **LIBS** — laser-induced breakdown spectroscopy → [[OES vs XRF vs LIBS]].
- **Matrix** — the bulk element/composition of the sample →
  [[Spectral interferences and matrix effects]].
- **NDIR** — non-dispersive infrared detection (C/S, O/H) →
  [[Carbon-sulfur combustion analysis]].
- **Paschen–Runge** — fixed-slit polychromator mount →
  [[Optical system - Paschen-Runge and Rowland circle]].
- **PDA / SDA** — single-spark distribution analysis →
  [[Single spark evaluation (PDA-SDA)]].
- **PMT** — photomultiplier tube detector → [[Detectors - PMT vs CCD-CMOS]].
- **PMI** — positive material identification (field verification) → [[OES vs XRF vs LIBS]].
- **Plasma** — hot ionised gas of the discharge →
  [[Plasma formation and excitation temperature]].
- **Pre-spark / pre-burn** — cleaning discharges before measurement →
  [[Spark and arc excitation]].
- **Profiling** — wavelength re-alignment onto slits/pixels →
  [[Type standardization and drift correction]].
- **Repeatability / Reproducibility** → [[Detection limits, precision and accuracy]].
- **Rowland circle** — geometry that focuses a concave grating →
  [[Optical system - Paschen-Runge and Rowland circle]].
- **RSD** — relative standard deviation (precision %) →
  [[Detection limits, precision and accuracy]].
- **Self-absorption** — line flattening at high concentration →
  [[Spectral interferences and matrix effects]].
- **SPC** — statistical process control of results → [[Quality control and SPC]].
- **Spark stand** — chamber where sample meets spark →
  [[Spark stand and counter electrode]].
- **Standardisation / type standardisation** — drift correction with recal samples →
  [[Type standardization and drift correction]].
- **TCD** — thermal-conductivity detector (N/H) → [[ONH inert gas fusion analysis]].
- **VUV (vacuum ultraviolet)** — <200 nm region (C,P,S,N) →
  [[Vacuum vs purged vs sealed optics]].
- **XRF** — X-ray fluorescence → [[OES vs XRF vs LIBS]].
