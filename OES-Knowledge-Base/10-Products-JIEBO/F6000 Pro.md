# F6000 Pro Handheld XRF Analyzer

> Handheld **X-ray fluorescence** gun for fast, non-destructive alloy ID and sorting. Background:
> [[OES vs XRF vs LIBS]].

## Specifications

| Spec | Value |
|---|---|
| Type | Handheld XRF |
| Excitation | High-power miniature X-ray tube 50 kV / 100 µA / 4 W |
| Detector | Si-PIN |
| Element range | **Ti to U** |
| Filters | 6-position automatic |
| Connectivity | WiFi / Bluetooth / USB 3.0 |
| Battery | 6800 mAh Li-ion, ~8 h |
| Environment | Stable operation to 50 °C |

## Highlights
- **Non-destructive, no prep, ~1–2 s** readings — great for finished parts and field PMI.
- Broad heavy-element range (Ti–U); 6 filters auto-switch for sensitivity.
- **Cannot measure carbon** (or P/S/B reliably) — for carbon use [[Surpass F1|mobile OES]] or a
  lab OES; see [[OES vs XRF vs LIBS]].

## Best for
Metal recycling/scrap sorting, unknown-material ID, petrochemical/piping PMI, stainless, precious
metals, special alloys. Operator radiation-safety licensing usually applies (X-ray tube).
