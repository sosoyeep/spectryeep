# ONH-508 Oxygen, Nitrogen & Hydrogen Analyzer

> Inert-gas-fusion analyser for the **dissolved gases** in metals — O, N, H. Background:
> [[ONH inert gas fusion analysis]].

## Specifications

| Spec | Value |
|---|---|
| Type | Inert-gas-fusion O / N / H analyser |
| Measuring range | O 0.5 ppm–20 % / N 0.5 ppm–50 % / H 0.2 ppm–0.1 % |
| Accuracy | O 1 ppm or RSD ≤1.0 % / N 1 ppm or ≤1.0 % / H 0.2 ppm or ≤2.0 % |
| Minimum reading | 0.01 ppm |
| Analysis time | 120–240 s |
| Methods | O: NDIR · N: thermal-conductivity (TCD) · H: NDIR |
| Balance accuracy | 0.0001 g |
| Furnace | 220 VAC, ≤8.5 kVA, ≤1500 A, ≤3000 °C |
| Carrier gas | High-purity He 99.99 % (power gas: N₂ / purified compressed air) |
| Dimensions (L×W×H) | 600 × 700 × 900 mm |
| Weight | 160 kg |

## Highlights
- Measures the gases **OES can't** — critical for cleanliness, toughness and **hydrogen
  embrittlement** ([[ONH inert gas fusion analysis]]).
- ppm → percent ranges with high accuracy; matrix-independent.
- Standards: ASTM E1019 / E1409 / E1447; GB/T 11261, 20124 ([[ISO and EN methods]],
  [[Chinese GB-T standards]]).

## Best for
Steel, titanium, nickel, copper and rare-earth labs controlling O/N/H — complements
[[Iron and steel analysis|OES]] and [[Carbon-sulfur combustion analysis|C/S]] in a full metals
lab.
