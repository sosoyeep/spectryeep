# F7000 Pro Handheld LIBS Analyzer

> Handheld **laser-induced breakdown spectroscopy** gun — sub-second alloy sorting with
> light-element capability and no X-ray regulation. Background: [[OES vs XRF vs LIBS]].

## Specifications

| Spec | Value |
|---|---|
| Type | Handheld LIBS |
| Laser | Class 3B |
| Elements | Be, Mg, Al, Si, Ti, Cr, Mn, Fe, Ni, Cu, Zn, Cd, Sn, Pb, Bi, Mo, V, Nb, W … |
| Analysis speed | < 1 s |
| Weight | 1.25 kg (incl. battery) |
| Safety | Contact-required interlock (laser fires only against the target) |

## Highlights
- **Sub-second** results; **light, 1.25 kg**; **no X-ray** → simpler transport/licensing than
  [[F6000 Pro|XRF]].
- **Light-element capable** (Be, Mg, Al, Si …) — better than XRF for those; gives a rough
  **carbon-equivalent** sort, though not lab-OES carbon accuracy.
- Leaves a sub-mm mark (practically non-destructive in PMI).

## Best for
Fast field sorting/PMI, light-alloy work, scrap where speed and portability win over
certification-grade accuracy. For true carbon/certification use [[Surpass F1|mobile OES]] or a
lab OES. See [[OES vs XRF vs LIBS]].
