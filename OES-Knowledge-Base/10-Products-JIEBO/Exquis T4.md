# Exquis T4 OES Spectrometer

> Compact **sealed-cycle argon optics** benchtop spark OES — JIEBO's low-maintenance
> entry/mid lab unit (33 kg).

## Specifications

| Spec | Value |
|---|---|
| Type | Compact benchtop spark OES |
| Matrix | Fe, Al, Cu, Zn |
| Elements | 50+ |
| Optical system | [[Optical system - Paschen-Runge and Rowland circle\|Paschen–Runge]] |
| Grating focal length | 401 mm |
| Wavelength range | **160–580 nm** |
| Detector | Low-noise **CMOS** — [[Detectors - PMT vs CCD-CMOS]] |
| Optical chamber | **Sealed-cycle (argon)** — [[Vacuum vs purged vs sealed optics]] |

| Operating temp / humidity | 10–30 °C / 20–80 %RH |
| Dimensions (L×W×H) | 525 × 635 × 290 mm |
| Weight | **33 kg** |

## Highlights
- **Sealed-cycle optics** → no vacuum pump, minimal purge gas → **lowest upkeep / cost of
  ownership** ([[Total cost of ownership and consumables]]).
- High UV sensitivity for the elements in its range; compact footprint.
- Simplest to site and run of the JIEBO OES line.

## Best for
Single-/few-matrix shops (e.g. a steel or aluminium foundry) wanting a small, affordable,
low-maintenance OES. Range is narrower at the extreme VUV than the vacuum [[Innovate T5]] /
[[JB-750]].
