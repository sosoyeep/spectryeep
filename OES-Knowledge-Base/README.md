# OES Spectrometer Knowledge Base

An [Obsidian](https://obsidian.md) vault that consolidates **authoritative and technical
reference material on Optical Emission Spectrometry (OES)** for metal analysis — the physics,
the instrumentation, sample preparation, calibration, applications, standards, and the JIEBO
Instrument product line.

## How to open

1. Install Obsidian (free).
2. **Open folder as vault** → select this `OES-Knowledge-Base/` folder.
3. Start at [[Home]] (`00-Maps/Home.md`). Every note is cross-linked with `[[wikilinks]]`;
   use the **graph view** to see how topics connect.

## Structure

| Folder | Contents |
|---|---|
| `00-Maps` | Maps of Content (MOCs) — the entry points and topic indexes |
| `01-Fundamentals` | The physics: atomic emission, spark/arc excitation, plasma, interferences |
| `02-Instrumentation` | Hardware: source, optics, gratings, detectors, argon, spark stand |
| `03-Sample-Preparation` | Surface prep, requirements by matrix, small samples & chips |
| `04-Calibration-and-QA` | CRMs, type standardization, drift, QC, single-spark evaluation |
| `05-Applications` | Steel, cast iron, aluminium, copper, nickel; foundry melt control |
| `06-Standards` | ASTM, ISO/EN, and Chinese GB/T test methods |
| `07-Comparison` | OES vs XRF vs LIBS; combustion C/S; inert-gas-fusion O/N/H |
| `08-Selection-and-Buying` | Choosing an instrument, stationary vs portable, cost of ownership |
| `09-Maintenance-Troubleshooting` | Routine care and fault diagnosis |
| `10-Products-JIEBO` | JIEBO instrument line, one note per model |
| `99-Reference` | Glossary, analytical spectral lines, sources & further reading |
| `Templates` | Note templates |

## Conventions

- **Tags** group notes by theme: `#fundamentals`, `#instrumentation`, `#sample-prep`,
  `#calibration`, `#application`, `#standard`, `#comparison`, `#buying`, `#maintenance`,
  `#product`, `#reference`.
- **Frontmatter** carries `aliases` (so acronyms resolve) and `tags`.
- Each note ends with a **Related** section of wikilinks.

## Accuracy note

Technical content reflects established OES practice. **Standard numbers and editions, and
manufacturer specifications, should always be verified against the current published
documents** before being used for compliance, procurement, or certification. See
[[Sources and further reading]]. Product specifications are sourced from the JIEBO 2026
brochure and may be revised by the manufacturer.
